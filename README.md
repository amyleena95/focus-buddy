# 🐱 Focus Buddy — Tondu Edition

*A little productivity companion with a big personality.*

Focus Buddy is a cute desktop Pomodoro timer built with **Python and Tkinter**, featuring a virtual pet named Tondu.

Inspired by a real gray-and-white tabby American short-hair cat, Tondu keeps you company while you work. Complete focus sessions, take care of your virtual cat, and build better productivity habits together!

## ✨ Features

### ⏱️ Pomodoro Timer
- 25-minute focus sessions.
- 5-minute break sessions.
- Start, pause, reset and skip controls.
- Visual progress bar.
- Automatic session switching.

### 🐾 Virtual Pet System
Take care of Tondu while you work!

- ❤️ **Happiness:** Increases when you pet or play with Tondu.
- 🍗 **Hunger:** Increases over time. Remember to feed him!
- ⚡ **Energy:** Decreases over time and when playing.
- 😸 **Mood:** Changes depending on Tondu's needs.
- 🧶 **Interactions:** Pet, feed, play and let Tondu sleep.

### 💾 Save System
- Automatically saves Tondu's stats.
- Remembers his progress between application sessions.
- Applies basic hunger and energy changes while the application is closed.

### ✏️ Customisation
- Give your virtual pet a custom name.
- Adjust the application and pet system as you develop your own companion.

## 🛠️ Built With

- Python 3
- Tkinter
- JSON for local data storage

No additional Python packages are required for the current version.

## 🚀 Getting Started

### Prerequisites

- Windows 10 or later
- Python 3 installed
- Tkinter available with your Python installation

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/focus-buddy.git
   ```

2. Navigate to the project directory:

   ```bash
   cd focus-buddy
   ```

3. Run the application:

   ```bash
   python focus_buddy.py
   ```

That's it! Tondu is ready to meet you.
